# Object Detection, Segmentation and Pose Estimation Using YOLOv8

This project demonstrates multiple computer vision tasks using the Ultralytics YOLOv8 framework.

## Features

- Object Detection
- Instance Segmentation
- Human Pose Estimation
- Confidence Score Extraction
- Bounding Box Visualization

## Technologies

- Python
- Ultralytics YOLOv8
- OpenCV
- PyTorch

## Models Used

- YOLOv8n
- YOLOv8n-seg
- YOLOv8n-pose

## Workflow

1. Load YOLOv8 models
2. Detect objects in images
3. Draw bounding boxes and labels
4. Perform instance segmentation
5. Estimate human body keypoints
6. Visualize prediction results

## Goal

The purpose of this project is to explore modern real-time computer vision techniques using YOLOv8 for object detection, image segmentation, and human pose estimation.
